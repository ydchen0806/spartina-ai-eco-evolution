# Public clonal-trait source data

Xincong Chen (2026), *clonal traits data of the invasive Spartina alterniflora in China*.
Figshare version 1, https://doi.org/10.6084/m9.figshare.33329481.v1.
Licence: CC-BY-4.0. The source CSV is unmodified and verified against the
provider MD5. See download_manifest.json for SHA-256 and the public file URL.

The API record supplies a brief description but no linked article or separate
README. Experimental calendar, block semantics, genotype/seed-family identity
and missingness explanations are not supplied. Do not fill these gaps by
assuming that Block denotes year, cohort or genotype, or that emergence day is
a known calendar date. Abbreviated environmental column units are not fully
documented. Interpret source population and garden effects conditionally.

Reanalysis products reside in data/derived/clonal_common_garden_20261007/.
Our analyses are not endorsed by the source author.
